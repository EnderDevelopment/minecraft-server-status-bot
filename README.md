# ServerStatusPlugin

ServerStatusPlugin is a Minecraft plugin designed to display and update the server status. It provides a simple command to check the server's online status and the number of players currently connected. This plugin is ideal for server administrators who want to quickly monitor their server's status without needing to access the server console or other monitoring tools.

## Install

1. Download the ServerStatusPlugin JAR file from the releases section.
2. Place the JAR file in the `plugins` directory of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Once the server is running with the plugin installed, players can use the `/serverstatus` command to check the server's status.
2. The plugin will respond with the server's online status and the number of players currently online.
